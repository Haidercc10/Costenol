COSTEÑOL - ACTUALIZACIÓN 24/11/2026

Las reglas de esta nota ya están integradas en el Manual del programador y la Guía de sustentación, actualizados el 24/11/2026.

1. CAPTURAS CON TIPO ESTRICTO
La asignación directa de una captura exige el mismo tipo que la variable.
Incorrecto: n Real; n = Captura.Entero();
Correcto:   n Real; n = Captura.Real();
También se valida si la captura está entre paréntesis.
El error semántico propone la captura correcta antes de ejecutar o pedir datos.
Asignar un valor entero a Real sigue permitido: n Real; n = 4;

2. SEPARACIÓN DE Si
Incorrecto: Si(Verdadero) FinSi
Correcto:   Si (Verdadero) FinSi
El error sintáctico indica línea, columna y la separación que falta.
No se exige esa separación en Mensaje.Texto() ni Captura.Real().
