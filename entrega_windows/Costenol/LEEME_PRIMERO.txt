COSTEÑOL - PRUEBA PORTABLE PARA WINDOWS

1. Extrae TODO el ZIP en una carpeta del otro equipo, por ejemplo Documentos/Costenol.
2. Abre la carpeta Costenol y haz doble clic en Costenol.exe.
3. Conserva _internal junto al .exe. No copies solamente el ejecutable.

REQUISITOS
Windows 10 u 11 de 64 bits (x64). No requiere instalar Python, pip ni VS Code.
No necesita conexión a Internet para analizar y ejecutar los programas.
Esta entrega está diseñada para ejecutarse desde una carpeta con permiso de escritura.
No es una versión para macOS, Linux o Windows ARM nativo.

LOGO E ICONOS
El ejecutable incorpora el isotipo de Costeñol sin letras en varios tamaños.
La ventana usa ese mismo símbolo y una identidad propia en la barra de tareas.
La cabecera y la bienvenida incluyen los logos de Costeñol. No borres _internal/logo.

PRUEBA GUIADA EN EL OTRO EQUIPO
[ ] Iniciar Costenol.exe y comprobar bienvenida, logo y ventana principal.
[ ] Comprobar el icono de Costeñol en la barra de tareas al abrir la aplicación.
[ ] Cambiar Claro/Oscuro con el switch y comprobar el logo apropiado.
[ ] Abrir ejemplos/ejemplo_ejecucion.pqek y pulsar F5.
[ ] Pulsar F6 e introducir Ana, 20, 12,5, Verdadero.
[ ] Comprobar saludo, Mayor de edad, asistencia y total 25,0.
[ ] Abrir un segundo ejemplo, cambiar de pestaña y volver sin perder el texto.
[ ] Crear archivo nuevo y escribir: edad Entero; edad = "Hola";
[ ] Esperar el error automático; comprobar categoría, línea y mensaje costeño.
[ ] Corregir a edad = 20; y comprobar que desaparece el diagnóstico.
[ ] Guardar como prueba_portable.pqek, cerrar la pestaña y volver a abrir el archivo.
[ ] Cerrar el programa y confirmar que no queda una bienvenida abierta.
